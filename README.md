# CarPick — сайт-помощник выбора б/у автомобиля

Статический сайт, который помогает покупателю б/у авто не купить проблемную машину.

## 🎯 Цель проекта
Покупатель б/у автомобиля тонет в объявлениях: не понимает, какие модели надёжны, сколько стоит обслуживание, на что смотреть при осмотре.  CarPick собирает всё в одном месте.

## ✨ Ключевые функции
- **Каталог моделей** — плюсы, минусы, типичные поломки, стоимость запчастей, расход.
- **Сравнение** — 2–3 модели side-by-side по ключевым параметрам.
- **Калькулятор стоимости владения** — топливо, ТО, страховка, налог, амортизация.
- **Чек-лист осмотра** — что проверить при покупке, можно распечатать.

## 🚀 Как запустить
Просто открой `CarPick.html` в браузере. Сайт статический, без сборки и бэкенда.
